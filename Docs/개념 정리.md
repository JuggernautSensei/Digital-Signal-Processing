# 개념 정리

디지털신호처리 수업을 들으며 정리한 노트를 실습 순서에 맞춰 다시 묶은 문서입니다.

## 1. 디지털 신호 처리의 흐름

연속 신호를 디지털로 처리하는 시스템은 다섯 단계로 구성됩니다.

| 단계 | 역할 |
|---|---|
| 전처리 필터 | 샘플링 전에 신호의 주파수 범위를 제한해 주파수 중첩을 줄임 (안티 에일리어싱 필터) |
| A/D 변환 | 샘플링 → 양자화 → 부호화. 양자화 과정에서 오차가 생김 |
| 디지털 시스템 | 하드웨어와 소프트웨어로 신호를 처리 |
| D/A 변환 | 복호화 후 이산 값을 연속 신호로 복원. 0차 홀드, 1차 홀드 같은 보간을 사용 |
| 후처리 필터 | 복원 과정에서 생긴 불필요한 성분을 제거하고 매끄럽게 만듦 |

시간 영역 표현(파형)과 주파수 영역 표현(스펙트럼)은 같은 신호를 다른 변수로 기술한 것입니다. 표현만 달라질 뿐 신호의 본질은 변하지 않습니다.

## 2. 신호

- **임펄스 δ[n]**: 모든 이산 신호는 시간 이동한 임펄스의 가중합으로 표현할 수 있습니다.
  x[n] = Σ x[k] δ[n − k]
- **계단 u[n]**: n ≥ 0에서 1. 다른 신호를 켜고 끄는 스위치처럼 쓸 수 있습니다.
- **복소 정현파 e<sup>jΩn</sup>**: 연속 정현파는 항상 주기 함수지만, 이산 정현파는 2π/Ω가 유리수일 때만 주기 함수입니다.
- **이산 주파수의 모호성**: 각주파수 Ω와 Ω + 2πk는 같은 수열을 만듭니다. 이산 신호는 시간 척도 정보가 없는 단순한 수열이기 때문입니다. 따라서 이산 정현파는 0 ≤ Ω < 2π 범위에서만 구별됩니다.
- **에너지와 전력**: 에너지는 Σ|x[n]|², 전력은 그 시간 평균입니다. 데시벨은 전력비에 10 log, 크기비에 20 log를 사용합니다.

## 3. 시스템

| 성질 | 판별 기준 |
|---|---|
| 선형성 | 가산성과 동차성을 모두 만족 |
| 시불변성 | 입력을 지연시키면 출력도 똑같이 지연됨. 식에 시간에 따라 변하는 계수가 없음 |
| 인과성 | 현재 출력이 미래 입력에 의존하지 않음. h[n] = 0 (n < 0) |
| 안정성 (BIBO) | 유한한 입력에 유한한 출력. Σ\|h[n]\| < ∞ |
| 기억성 | 현재 출력이 과거 입력에 의존하면 동적 시스템, 현재 입력만 쓰면 순시 시스템 |

**LTI 시스템**은 임펄스 응답 h[n] 하나로 완전히 기술되고, 출력은 입력과 임펄스 응답의 컨벌루션입니다.

$$
y[n] = x[n] * h[n] = \sum_{k} x[k]\,h[n-k]
$$

- **FIR**: 임펄스 응답의 길이가 유한. 차분 방정식이 이동평균 항으로만 구성됩니다.
- **IIR**: 임펄스 응답의 길이가 무한. 차분 방정식에 자기회귀 항(과거 출력)이 있습니다.

## 4. 샘플링과 양자화

- 샘플링 주기 T<sub>s</sub>로 샘플링하면 x[n] = x(nT<sub>s</sub>)이고, 디지털 각주파수는 Ω = ωT<sub>s</sub>입니다.
- 샘플링하면 스펙트럼이 샘플링 주파수 f<sub>s</sub>의 정수배마다 반복됩니다.
- **나이퀴스트 샘플링 정리**: 대역 제한 신호의 최고 주파수를 f<sub>max</sub>라 할 때 f<sub>s</sub> > 2f<sub>max</sub>이면, 반복된 스펙트럼이 겹치지 않아 이상적인 저역 통과 필터로 원 신호를 복원할 수 있습니다.
- **에일리어싱**: 조건을 만족하지 못하면 f<sub>s</sub>/2(꺾기 주파수)를 기준으로 주파수가 접혀 더 낮은 주파수로 복원됩니다. 복원 신호의 주파수는 f<sub>s</sub>/2를 넘을 수 없습니다.
- 실제로는 이상적인 저역 통과 필터를 만들 수 없고 실제 신호는 대역 제한되어 있지 않으므로, 샘플링 주파수를 충분히 높이고 안티 에일리어싱 필터를 함께 사용합니다.
- **양자화**: b비트 양자화기의 간격은 Δ = R / 2ᵇ이고, 양자화 오차는 ±Δ/2 범위에 있습니다.

## 5. 푸리에 해석

### 출발점: 직교 기저

내적이 0인 두 함수를 직교한다고 합니다. sin과 cos은 한 주기 구간에서 직교하므로 기저로 삼을 수 있고, 주기 함수를 이들의 선형 결합으로 표현할 수 있습니다. 오일러 공식 e<sup>jθ</sup> = cos θ + j sin θ를 쓰면 sin과 cos을 복소 지수 하나로 합칠 수 있습니다.

### 네 가지 변환의 관계

| | 시간 영역이 연속 | 시간 영역이 이산 |
|---|---|---|
| **주기 신호** | 푸리에 급수 (FS) → 이산 스펙트럼 | 이산 시간 푸리에 급수 (DTFS) → 이산·주기 스펙트럼 |
| **비주기 신호** | 푸리에 변환 (FT) → 연속 스펙트럼 | 이산 시간 푸리에 변환 (DTFT) → 연속·주기 스펙트럼 |

- 푸리에 급수의 주기를 무한대로 보내면 이산 주파수의 합이 연속 주파수의 적분으로 바뀌어 푸리에 변환이 됩니다.
- 시간 영역에서 샘플링(이산화)하면 주파수 영역이 주기적으로 반복되고, 시간 영역이 주기적이면 주파수 영역이 이산적입니다.
- **DFT**는 DTFT를 한 주기에서 N개 점으로 샘플링한 것으로, 시간과 주파수가 모두 이산·유한해서 컴퓨터로 계산할 수 있습니다. **FFT**는 DFT를 O(N log N)에 계산하는 알고리즘입니다.

### 실습에서 확인한 성질

| 성질 | 내용 | 실습 |
|---|---|---|
| 컨벌루션 | 시간 영역 컨벌루션 ↔ 주파수 영역 곱 | `ConvolutionByFT.m` |
| 대칭성 | 실수 신호에서 Re{X} = DTFT{x<sub>e</sub>}, j·Im{X} = DTFT{x<sub>o</sub>} | `DTFT_Symmetry.m` |
| 주파수 이동 | e<sup>jΩ₀n</sup>x[n] ↔ X(e<sup>j(Ω−Ω₀)</sup>) | `DTFT_FrequencyShift.m` |
| 원형 컨벌루션 | N점 DFT의 곱 ↔ 원형 컨벌루션. 길이를 N<sub>x</sub> + N<sub>h</sub> − 1 이상으로 영채우기하면 선형 컨벌루션과 같음 | `CircularConvolution.m` |

### 왜 주파수 영역으로 가는가

시간 영역은 언제 어떤 값이 나타나는지를, 주파수 영역은 어떤 주파수 성분이 얼마나 들어 있는지를 보여 줍니다. 실제 신호에는 원하는 성분과 잡음이 섞여 있어 시간 영역에서는 분리하기 어렵지만, 주파수 영역에서는 특정 성분만 골라 처리한 뒤 역변환으로 되돌릴 수 있습니다.

- **영상 처리**: 화면을 촬영할 때 생기는 모아레 무늬는 특정 주파수 성분으로 나타나므로, FFT 기반 필터로 원본 디테일은 남기고 무늬만 제거할 수 있습니다. M×N 영상에 m×n 커널을 직접 컨벌루션하면 O(MN·mn)이지만, FFT를 쓰면 O(MN log MN)으로 줄어듭니다.
- **전력 시스템**: 교류 전력망의 기본파에 섞인 3차, 5차 고조파는 시간 파형에서는 단순한 왜곡으로만 보이지만, 주파수 영역에서는 차수별 성분으로 정확히 분리됩니다.
